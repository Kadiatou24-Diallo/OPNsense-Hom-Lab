# Lab 01 - OPNsense Installation and Initial Configuration

## Objective
Install and configure OPNsense as the central firewall of the cybersecurity home lab.

## Environment
- VMware Workstation
- OPNsense Firewall
- VMnet8 (WAN)
- VMnet1 (LAN)

## Tasks Performed
1. Created the OPNsense virtual machine.
2. Attached the OPNsense ISO image.
3. Installed OPNsense.
4. Configured WAN and LAN interfaces.
5. Accessed the OPNsense web dashboard.
6. Verified firewall operation.

## Network Configuration

### WAN
- VMnet8 (NAT)
- Provides Internet connectivity

### LAN
- VMnet1 (Host-only)
- Network: 192.168.105.0/24

## Results
- OPNsense installed successfully.
- WAN and LAN interfaces operational.
- DHCP service enabled.
- Firewall dashboard accessible.
