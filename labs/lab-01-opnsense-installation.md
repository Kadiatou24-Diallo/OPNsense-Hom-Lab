# Lab 01 - OPNsense Installation

## Lab Objective
Install OPNsense and prepare the firewall for a cybersecurity home lab environment.

## Tools Used
- OPNsense
- VMware 

## Tasks Performed
1. Created the OPNsense virtual machine.
2. Attached the OPNsense ISO image.
3. Installed OPNsense.
4. Configured network interfaces.
5. Accessed the OPNsense web interface.
6. Verified basic connectivity.

## Result
The OPNsense firewall was successfully installed and is operational.

## Skills Learned
- Firewall deployment
- Virtual machine management
- Basic network configuration
- OPNsense administration
